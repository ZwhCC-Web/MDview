# MDView 1.0 使用指南

## 基本操作
- **实时预览**（默认）：单击任意段落即可编辑，`Esc` 或单击别处完成；`↑` `↓` 在块首 / 块尾时跳到相邻块。
- **源码模式** `Ctrl+/`、**分屏** `Ctrl+Alt+/`：CodeMirror 编辑器，支持多光标（Ctrl+单击）、矩形选择（Alt+拖动）、选中多行 Tab 整体缩进；分屏按行同步滚动，单击右侧预览可定位源码。
- **插入任何元素**：空行行首输入 `/`（可用拼音首字母过滤：`/bg` 表格、`/lct` 流程图、`/sx` 时序图、`/jcq` 寄存器图、`/db` 待办、`/ai` AI 写作）。
- **命令面板** `Ctrl+Shift+P`；**快速打开** `Ctrl+P`；在快速打开框输入 `=` 进入计算器（支持 `0x` `0b`、`<< >> & | ^ ~`、`k/M` 后缀，Enter 插入结果）。

## 文件与知识管理
- `Ctrl+Shift+O` 打开文件夹：文件树、全局搜索 `Ctrl+Shift+F`、双链 `[[笔记]]`、反向链接、关系图谱 `Ctrl+Shift+G`。
- 重命名文件时可自动更新所有引用它的链接。
- **待办汇总**（侧栏“待办”）：写 `- [ ] 事项 📅 2026-10-25`，自动按“已逾期 / 今天 / 7 天内 / 以后 / 无日期”分组；勾选直接写回原文件。`!!` 或 `🔺` 标记高优先级。
- **模板** `Ctrl+Alt+N`：会议纪要、周报、客户问题跟踪（FAE）、样品申请 / 物流跟踪、芯片评估笔记、培训讲稿（幻灯片）、邮件草稿、技术方案评审；在文件夹中建 `templates/` 目录放自己的模板。
- **今日工作日志** `Ctrl+Alt+D`：在 `日志/` 下创建当天文件。
- **历史版本** `Ctrl+Alt+H`：每次保存自动留存，可对比差异、一键恢复。

## 图片
- 截图后直接粘贴：图片自动保存到文档旁的 `assets/`（宽度超过 1920px 自动缩小），并插入相对路径。
- 右键图片：缩放 25% / 50% / 75% / 原始大小、全屏查看、在资源管理器中显示。
- 网页版打开带本地图片的文档时，单击顶部“授权文件夹”即可显示。

## 导出与分享
| 目标 | 菜单 |
|---|---|
| Word | 文件 → Word 文档 (.docx) |
| PPT | 文件 → PowerPoint 幻灯片 (.pptx)：`---` 分页，`<!-- notes: 讲稿 -->` 为演讲者备注 |
| Outlook | 文件 → Outlook 邮件草稿：桌面版直接打开新邮件窗口；或“复制为邮件格式”后粘贴 |
| PDF | `Ctrl+Alt+P`（带页码） |
| 网页 | HTML / HTML（图片内嵌，单文件发送）/ 幻灯片 HTML |
| 演示 | `F5` 全屏演示幻灯片 |

## AI 助手（`Ctrl+J`）
1. AI → AI 服务设置：选择 OpenAI 兼容接口、Azure OpenAI 或 Ollama（本地），填写地址 / Key / 模型，点“测试连接”。
2. 选中文字 → 浮动工具栏“AI” → 润色 / 精简 / 续写 / 中英日翻译 / 整理成表格 / 解释代码；或在面板中直接描述要求。
3. 整篇文档：总结要点、整理会议纪要（带待办）、起草邮件、生成幻灯片大纲。
4. 结果可“替换原文”（可撤销）、“对比”、“插入到光标处”、“新建文档”。
> 处理公司资料前请确认符合信息安全规定；需要数据不出本机时请使用 Ollama 本地模型。
