# 更新日志

## 1.0.0（首个正式版）
**编辑内核**
- 全面采用 CodeMirror 6：源码 / 分屏为完整 CodeMirror 编辑器；实时预览中每个块也用 CodeMirror 编辑。CodeMirror 内嵌在单个 HTML 中，离线可用；加载失败时自动降级。
- 大文档性能：2 万行文档源码模式打字延迟约为原生文本框的 1/3；实时预览块分组渲染，块内打字延迟从约 360 ms 降到约 18 ms。

**图片（修复）**
- 修复：带空格 / URL 编码 / 反斜杠 / Windows 绝对路径 / `file:///` 的图片无法显示；未解析前出现破图标或错误请求；找不到图片时没有提示；图片文件更新后不刷新；导出 HTML 时本地图片丢失。
- 网页版新增“授权文件夹”提示条；粘贴大图自动缩小。

**界面打磨**
- 全新视觉：中日文字体栈、标题层级与间距、表格 / 代码块 / 引用 / 提示框样式、待办复选框与截止日期标签、SVG 图标、分段模式切换、菜单 / 弹窗 / 提示动画、深色主题配色。
- 分屏按行同步滚动；模式切换保持阅读位置；PDF 打印带页码。

**新功能**
- AI 助手：OpenAI 兼容 / Azure OpenAI / Ollama，流式输出，选中即用的润色 / 翻译 / 表格化 / 解释代码，整篇总结 / 会议纪要 / 邮件 / 幻灯片大纲，替换前对比。
- MCP 服务：Copilot / Claude / Cursor 可列出、搜索、阅读、修改笔记，汇总待办，读取 MDView 当前文档与选区。
- 原生导出 Word / PowerPoint（含演讲者备注）/ Outlook 邮件草稿 / 复制为邮件格式，无需 Pandoc。
- 待办汇总面板（截止日期、逾期、优先级，勾选写回文件）。
- 模板库（会议纪要、周报、FAE 问题跟踪、样品申请、芯片评估、培训讲稿、邮件、方案评审）+ 自定义模板 + 今日工作日志。
- 命令面板内计算器（十六进制 / 二进制 / 位运算）；表格排序、复制到 Excel；插入当前日期时间。
