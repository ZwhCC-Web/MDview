# IP Studio（.cbip）

一个 IP（例如 RH850/U2B 的 RS-CANFD）对应一个 `.cbip` 文件。它是**工程上的唯一事实来源**；IP Studio 只是它的一个视图。结构、寄存器、场景、行为规则、时序图都在这一个文件里，改名 / 删除时彼此保持一致。

> 本页描述 2.4.0 的实际行为。**时序图目前只有数据层和 MCP，界面里还不能查看 / 编辑**（见“时序图”一节）。

## 文件
| 文件 | 谁写 | 内容 |
|---|---|---|
| `name.cbip` | 你 / 经你确认的 AI | 节点、端口、连线、参数、寄存器、场景、规则、时序图、各自的依据 |
| `name.cbip.layout.json` | 你（应用） | 折叠、聚焦、方向、适应宽度、手动摆放的偏移、右侧面板是否显示；AI 不会改 |
| `name.cbip.proposal.json` | AI（MCP） | 等待你接受 / 拒绝的修改 |

## 打开与创建
- 打开 `.cbip` 文件即进入 IP Studio；命令面板里有“新建 IP 模型…”“把 IP 图谱页转换为 IP 模型…”“从模板添加…”“从 SVD 导入寄存器…”。
- **新建**可以从空白开始，也可以从 12 个内置模板开始：CAN / CAN-FD、以太网 MAC、DMA、定时器 / PWM、串口、Flash、RAM 与 ECC、GTM、时钟与复位、多核、CPU 内核、中断控制器。模板**只描述结构**，条目一律“示意”，不含容量、通道数、地址、复位值、时序数字；用它创建的模型是“实例”，所有节点和连线是“待核对”，由你对照手册补事实和页码。
- **转换 IP 图谱页**：把 Markdown 页里的 ` ```ipblock `、` ```register `、` ```scene `、` ```wavedrom ` 一起迁移（页面本身不改）。对不上的引用会逐条列出并跳过，不会静默丢失。

## 依据等级
手册确认 · 实测 · 推导 · 示意 · 待核对。**“手册确认”必须有页码**；没有页码的只能是“推导 / 示意 / 待核对”。模板里一律“示意”。每个节点、连线、寄存器、位域、场景、规则、时序图各有自己的等级。校验会统计“还没有手册确认或实测依据”的条目。

## 27 个操作
所有修改——你在界面里点的，或 AI 通过 MCP 提的——都由这 27 个原子操作完成。**一批操作要么全部生效，要么全部不生效**，失败时一次列出全部问题。每次修改在界面里是一步可撤销（最多 50 步）。

| 类别 | 操作 |
|---|---|
| 结构（14） | add_node · remove_node · update_node · rename_node · add_port · remove_port · add_edge · remove_edge · set_param · set_registers · define_register · remove_register · set_evidence · set_meta |
| 场景（7） | add_scene · remove_scene · update_scene · add_step · update_step · remove_step · move_step |
| 规则（3） | add_rule · update_rule · remove_rule |
| 时序图（3） | add_timing · update_timing · remove_timing |

**一致性**：重命名节点会同步场景高亮和 `emit @节点`；删除节点 / 端口 / 连线 / 寄存器会从场景步骤里移除对应引用；**删除被规则引用的寄存器会被拒绝**并指出是哪些规则（公式不会被自动改写）。

## 界面
- **图**：ELK 自动布局；点击节点选中；Ctrl+F 搜索（命中高亮，回车逐个跳转）；工具栏有折叠分组、适应 / 100 %、横向 / 纵向、SVG 导出、撤销。
- **右侧面板**（工具栏“面板”按钮显示 / 隐藏）：详情 · 寄存器 · 场景 · 规则 · 校验 · 修改 · 引用。窗口较窄（编辑区 < 880 px）时默认收起，点选节点、录制场景步骤、点“校验 / 待确认修改”时自动打开；手动点过之后按你的选择，并记在 `.layout.json`。
- **手动编辑结构**：选中节点后“编辑结构”里有添加子节点、添加端口、连线到…、重命名、删除；工具栏有“＋ 节点”。连线行尾的 × 删除这条连线。
- **从 SVD 导入寄存器**：命令“IP 模型：从 SVD 导入寄存器…”（MCP：`ip_import_svd`）。SVD 是厂商数据，不是手册，所以依据一律“待核对（SVD）”；已有寄存器不会被覆盖（自动加后缀）。

## 手动摆放、框选与多选
- **拖动节点或分组 = 移动**。位置存成偏移量写进 `.layout.json`，**模型文件不变**，也不会重新跑自动布局。移动分组时成员一起走；分组框会随成员变大。工具栏“重置位置”清除全部，详情页“恢复自动位置”清除一个。
- 放到**另一个节点上**才是连线 / 移入；把分组里的成员拖到分组外的空白处会问：留在分组里（分组变大），还是移出分组。轻微抖动仍算点击。
- 连线跟着走：两端都随容器一起移动的连线保留自动布局的走线，只有一端移动的重新走一条 3 段直角线（**不避开其它节点**）。
- **框选**：在空白处拖矩形。**多选**：Shift / Ctrl + 点击；Esc 取消。多选后右侧显示“已选 N 个”：放进新分组…、删除所选…（先说明连带多少节点和连线）、复制 id 列表、恢复自动位置；拖动其中一个 = 一起移动。录制场景步骤时，矩形把框到的节点加入这一步。
- **小地图**：节点 ≥ 25 且图需要滚动时出现在图的右下角，点击或拖动跳转。

## 大模型
节点很多时 IP Studio 做了专门处理（实测见 `docs/CHANGELOG.md` 的 2.2.0）：
- 块数 > 120 且有 ≥ 2 个顶层分组时，**默认打开“概览”**：每个顶层分组折叠成一个块，平行连线合并成一条“×N”。双击分组只展开它；“展开全部…”会先确认并提醒很慢。概览是**推导出来的，不写盘**；你自己折叠 / 展开之后才写入 `.layout.json`。聚焦子图时不用概览。
- 块数 > 80 时关闭逐节点动效；场景步骤和搜索的高亮改用“面纱”（一块半透明面纱 + 只克隆被点亮的节点），代价跟被点亮的数量有关，而不是跟图的大小有关。
- 布局参数按规模调整；超时随规模放宽，布局期间显示进度；布局失败时写明原因 / 影响 / 下一步，并提供“折叠成概览”和“重试”。
- 实测（无头软件渲染 Chromium，只用来发现退化）：300 / 1000 / 2850 个节点，打开 464 / 711 / 1552 ms，点击节点 35 / 49 / 61 ms，场景切一步 27 / 31 / 31 ms。**展开全部仍慢**：1000 个节点约 6 秒，2850 个约 21 秒。

## 场景
场景是在结构图上一步一步讲清楚“发生了什么”。每一步有标题、说明、高亮的节点和连线、寄存器写入（值 + 说明）、代码行和依据。
- **播放**：“场景”页签 → 选场景 → 播放 / 暂停 / 上一步 / 下一步（← → 键，空格播放）。图上高亮当前步，其余变淡；寄存器写入按位域解码，并标出相对上一次写入**变化了的位域**和“之前”的值。
- **录制**：“录制下一步” → 在图上点节点（或框选）→ 勾选连线 → 添加寄存器写入 → 保存。编辑、上移 / 下移、删除步骤、重命名 / 删除场景、场景依据都是一步可撤销的修改。

## 行为规则与推演
场景只记录“写了哪些寄存器值”。**规则**让你把**手册里写明的行为**写下来，再把场景套上去，看规则推出什么。

> **它是什么，不是什么**：引擎**不认识任何芯片**，只执行写进模型的规则。每个结果都标“推导”，并列出它依赖的规则及其依据等级；用到了没有手册 / 实测依据的规则会提醒“视为假设”。**没有规则时它什么也不推导**，只重放场景里写的值，并这样告诉你。**请只在手册明确写了这个行为时才写规则，并写上页码**；凭印象写的规则会让推演看起来很确定，却没有依据。

**两类规则**
- **电平（level）**：条件成立时执行“满足时”，不成立时执行“否则”，用于“状态跟着条件走”（中断线 = 状态 & 使能）。动作不能读自己要写的目标（那是计数，会被拒绝并提示改成边沿）。
- **边沿（edge）**：条件由假变真的那一刻执行**一次**，用于计数、事件；条件一直为真时不重复触发；上电时已经为真视为“已激活”，不触发。没有“否则”。`emit` 只能用在边沿规则里。

**动作**：`set 名字 = 表达式`、`set 寄存器.位域 = 表达式`（位域赋值按位宽截断，不影响其它位）、`emit "文字" @节点`。

**表达式**：整数（十进制、`0x1F`、`0b101`、`1_000`）、`名字`、`寄存器.位域`、括号；运算符按 C 的优先级：`! ~ -`、`* / %`、`+ -`、`<< >>`、`< <= > >=`、`== !=`、`&`、`^`、`|`、`&&`、`||`。没有函数调用、字符串、赋值、属性访问。整数任意精度；比较和逻辑运算给 1 / 0；`/` `%` 向零取整。**除数为 0、移位个数超过 4096、表达式超过 400 字符、嵌套超过 48 层都是明确的错误**；表达式里的不可见 Unicode 字符也是错误（只认空格、制表、回车、换行）。手写解析器，没有 eval，规则来自人、AI 或共享文件，所以不可能执行代码。

**推演怎么跑**
1. 状态 = 寄存器值（起始为复位值，没有则 0）+ 变量（起始为 0）。
2. 每个场景步骤：先套用该步写入，再让规则“收敛”——按模型顺序逐轮执行，直到一轮没有变化；**最多 32 轮**，不收敛会明确报告（规则可能互相推翻），不会死循环。
3. 数值上限 1024 位（两条规则互相平方不会吃光内存）；规则最多 200 条。
4. 每个变化记录“是被哪条规则（或写入）改的”，精确到位域：只有真正翻转了该位域的原因才被归因。
5. 结果确定且可重复；推演不会改动模型。

**界面**：“规则”页签（添加 / 编辑 / 删除；条件和动作边输入边校验，错误文字与位置和模型拒绝时完全一致；“手册确认”必须写页码）。场景播放器里每一步下方显示“推演 · 推导”：推出的变化、起作用的规则（带各自的依据等级）、事件、警告；点击规则名跳到“规则”页签。**MCP**：`ip_simulate`（只读）。

## 时序图（仅数据层与 MCP）
`.cbip` 可以保存时序图：一组信号，每个信号一条 WaveDrom 风格的波形串，支持 `0 1 x z p P n N l L h H = 2–9 . |`（每个 `=` / `2–9` 段取一个数据标签；`.` 重复前一格；`|` 是间断）。
- **有**：3 个操作（add / update / remove_timing）、校验（不支持的波形字符、标签数量与段数不符、信号名重复、横向缩放必须 1–8、至少一个信号）、从 IP 图谱页的 ` ```wavedrom ` 迁移（分组 / 不支持的字符会逐条报告并跳过）、MCP 读写（`ip_read` 列出波形）。
- **没有**：**IP Studio 里还不能查看或编辑时序图**。校验页签能看到它们的问题，但看不到波形。需要看波形时仍用 Markdown 图谱页。
- 时序图是**手册里的图**，不是模型推出来的；请写上页码。

## AI 怎么用
`ip_read`（大模型用 `node` + `depth` 取子图）→ `ip_edit`（**默认是提案**，你在“修改”页签接受；只有你明确要求直接改时才用 `mode=write`）。`ip_validate` 检查悬空连线、端口类型 / 方向、位域重叠、复位值越界、缺页码、未确认的事实、规则引用错误。`ip_simulate` 逐步推演。`ip_templates` 列模板，`ip_create(template=…)` 从模板创建。工具说明里要求 AI：**写规则、画波形只依据手册并给页码；推测请标“推导 / 待核对”，宁可缺也不要编造**。

## 工作区
集合可引用整个模型或其中一个子图；点击子图引用会打开模型并聚焦到该节点。模型的“引用”页签列出被哪些集合引用。

## 已知限制
- **时序图没有界面**（见上）。
- **规则与推演**：只执行你写的规则，不会补全手册没写的行为；内置的 CAN-FD 页迁移后**没有任何规则**（产品不预置规则：规则必须来自手册并带页码），所以它的推演只重放寄存器写入。
- **手动摆放**只记偏移量：大改结构（增删节点、改分组）后，已有偏移仍按节点 id 生效，但自动布局会重新排其余部分，所以摆好的图可能需要再调。只有一端移动的连线用简单的 3 段直角线，不避开其它节点。
- 展开全部在节点很多时仍然慢（见“大模型”）。
- 900 px 宽度下同时打开项目侧栏和右侧面板时，图只有约 320 px 宽；用“面板”按钮或收起项目侧栏缓解。
- 场景里的“代码行”只记行号。
