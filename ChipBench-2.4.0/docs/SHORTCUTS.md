# 快捷键速查

## 文件与导航

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+N / Ctrl+O | 新建笔记 / 打开文件 |
| Ctrl+S / Ctrl+Shift+S / Ctrl+Alt+S | 保存 / 另存为 / 全部保存 |
| Ctrl+W | 关闭标签 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个标签 |
| Ctrl+P | 快速打开文件（输入 `=` 可做十六进制 / 位运算） |
| Ctrl+Shift+P | 命令面板 |
| Ctrl+Alt+H | 历史版本 |
| Ctrl+, | 偏好设置 |
| F1 | 快捷键与操作 |

## 视图

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+/ | 源码模式 |
| Ctrl+Alt+/ | 分屏模式 |
| Ctrl+Alt+E | 阅读模式 |
| Ctrl+Shift+U | 大纲 |
| F8 | 专注模式 |
| F11 | 全屏（隐藏侧栏与工具栏，顶部边缘呼出，Esc 退出） |
| F5 | 演示幻灯片 |
| Ctrl+Shift+R | 右侧面板 |
| Ctrl+Alt+R | 上下文面板（PDF 页 ↔ 笔记 / 组件） |
| Ctrl+Alt+D | 寄存器工作台 |
| Ctrl+Alt+G | 插入表格 |

## 格式

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+0 … Ctrl+6 | 正文 / 一至六级标题 |
| Ctrl+B / Ctrl+I | 粗体 / 斜体 |
| Ctrl+E | 行内代码 |
| Ctrl+K | 链接 |
| Ctrl+Shift+5 | 删除线 |
| Ctrl+Shift+H | 高亮 |
| Ctrl+Shift+Q | 引用 |
| Ctrl+Shift+K | 代码块 |
| Ctrl+Shift+M | 公式块 |
| Ctrl+Shift+I | 图片 |
| Tab / Shift+Tab | 表格单元格 / 列表缩进 |

## 工具

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+F / Ctrl+H | 查找 / 替换 |
| Ctrl+Alt+K | 数值换算器 |
| Ctrl+Alt+L | 技能库 |
| Ctrl+Alt+P | 导出 PDF / 打印 |

## PowerPoint 查看器

| 快捷键 | 功能 |
| --- | --- |
| PageDown / → | 下一页 |
| PageUp / ← | 上一页 |
| Home / End | 第一页 / 最后一页 |

> 以上以 3.0 的快捷键为准整理；若与你本机的实际绑定不一致，以 F1 面板为准。
