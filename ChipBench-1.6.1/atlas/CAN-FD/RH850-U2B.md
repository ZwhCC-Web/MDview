# CAN-FD · RH850/U2B（RS-CANFD）

## 概览

RS-CANFD 是 RH850/U2B 的 CAN FD 控制器（HW UM 第 24 章）。每个**单元**（RSCFD0 / RSCFD1）包含若干**通道**，每个通道有自己的**协议控制器**和**发送控制器**；同一单元内的通道共用**接收过滤器（AFL）**、**消息缓冲 RAM** 和**全局中断**。

理解它的主线：

1. **收**：协议控制器解出一帧 → AFL 按规则表找到第一条匹配 → 复制到 RX buffer / RX FIFO / CFIFO → 置标志、产生中断 → CPU 通过访问窗口读出。
2. **发**：CPU 把报文写进 TX buffer / TX queue / CFIFO → 发送控制器按 ID（或 buffer 号）优先级选出下一帧 → 协议控制器发出 → 回报 TMTRF、TX history 和中断。
3. **模式**：全局（GL_STOP / RESET / TEST / OPERATION）与通道（CH_STOP / RESET / HALT / COMMUNICATION）两级状态机；大部分配置只能在 RESET 类模式下写。

> 本页的数值、字段说明取自 RS-CANFD Lab v10.1（依据 HW UM R01UH0923EJ0130 Rev.1.30 第 24 章整理）。尚未逐项标注页码，状态为“待核对”。点击“实验台”可打开完整的交互实验（帧结构、位时序、错误限制、模式、存储、发送、Trace）。

## 时序

**位时间**：Tq = (BRP + 1) / fCAN；1 位 = 1（Sync）+ TSEG1 + TSEG2 个 Tq；采样点在 TSEG1 末尾。例：fCAN = 80 MHz，NBRP = 7，NTSEG1 = 15，NTSEG2 = 4 → 每位 20 Tq × 100 ns = 500 kbps，采样点 80%。

```wavedrom
{"signal": [
  {"name": "位段", "wave": "34.......5.", "data": ["Sync", "TSEG1（传播 + 相位 1）", "TSEG2"]},
  {"name": "采样", "wave": "0........10"}
], "config": {"hscale": 3}}
```

**CAN FD 帧与 BRS**：仲裁段用 NCFG；FDF = 1 且 BRS = 1 时，从 BRS 采样点到 CRC 界定符采样点使用 DCFG 的数据速率。

## 代码

初始化顺序（示意，寄存器名省略 `RSCFD0CFD` 前缀；需在实际工程中按 MCAL 规范实现）：

```c
while (GSTS & GRAMINIT) {}            /* 等 RAM 初始化完成 */
GCTR &= ~GSLPR;                       /* GL_STOP → GL_RESET */
while (GSTS & GSLPSTS) {}
C0CTR &= ~CSLPR;                      /* CH_STOP → CH_RESET */
while (C0STS & CSLPSTS) {}
GCFG = 0x00000022;                    /* DCE=1, CMPOC=1, DCS=0（clkc） */
C0NCFG = 0x061C0C07;                  /* 500 kbps @ 80 MHz, SP 80% */
C0DCFG = 0x03030E01;                  /* 2 Mbps */
GAFLECTR = AFLDAE;                    /* 打开规则表写窗口，page 0 */
/* GAFLID/M/P0/P1[j] = …; GAFLCFG0 = 规则数 */
GAFLECTR = 0;
RMNB = 0x00000710;  RFCC0 = 0x00007270; /* RX buffer / RX FIFO 0 配置 */
GCTR &= ~GMDC;                        /* → GL_OPERATION */
while (GSTS & GRSTSTS) {}
RFCC0 |= RFE;                         /* 使能 RX FIFO 0 */
C0CTR &= ~CHMDC;                      /* → CH_COMMUNICATION */
while (!(C0STS & COMSTS)) {}
```

接收中断（RX FIFO）：

```c
void ISR_INTRCANGRECC0(void) {
    uint32_t sts = RFISTS;               /* 哪个 FIFO 触发 */
    if (sts & 0x1) {
        while (!(RFSTS0 & RFEMP)) {
            uint32_t id = RFID0, ptr = RFPTR0, fd = RFFDSTS0;
            copy_data(&RFDF0_0, DLC2LEN(ptr >> 28));
            RFPCTR0 = 0xFF;                  /* 读指针前进 */
        }
        RFSTS0 = RFSTS0 & ~RFIF;             /* MOV 写 0 清 RFIF */
    }
}
```

## 要点与坑

- NCFG / DCFG / FDCFG 只能在 CH_RESET 或 CH_HALT 写；GCFG、RMNB、RFDC / RFPLS / RFIM 只能在 GL_RESET 写。
- AFL 是**首条匹配即停止**：宽掩码规则放在前面会遮住后面的规则；DLC 检查失败是整帧拒收，不会继续找下一条。
- RX buffer 没有接收中断，只置 RMND，需要轮询；RX FIFO 的中断 INTRCANGRECC 由单元内所有 FIFO 共用。
- 标志位用 MOV 写 0 清除，不要用位清除指令。
- 数据速率 > 2 Mbps 时 fCAN 只能选 clkc；5–8 Mbps 时同时使用的通道数 ≤ 6。
- 同一 ID 在网络中不能既用 FD 又用 Classical 格式。
