# 使用指南（ChipBench 1.0，沿用 Silica 3.0 的内容）

| 目的 | 做法 |
|---|---|
| 按项目组织资料 | 左侧「工作区」→ ＋ 添加文件夹 / 文件；用“集合”整理常用文档（可跨文件夹、一个文档可放多个集合）；文档仍在原处 |
| 切换项目 | Ctrl+Alt+W；切换时恢复上次打开的标签与模式 |
| 命令面板 / 快速打开 | Ctrl+Shift+P / Ctrl+P（命令面板里能找到全部功能，F1 查看快捷键） |
| 规划一天 | Ctrl+Shift+T：把待办拖进时间轴；Ctrl+Alt+T 开始 / 停止计时；Ctrl+Shift+W 看本周 |
| 打开手册 / 表格 / 固件 / 日志 | Ctrl+Shift+O；PDF 可从当前页生成结构图 |
| 插入图表 | 命令面板输入“插入”：时钟树、结构图、寄存器、引脚图、内存图、属性查询、曲线、Mermaid、公式 |
| 记一笔 | Ctrl+Alt+N（全局快捷键，窗口不在前台也能用） |
| AI | Ctrl+J；先在「AI 设置」里配置服务。处理公司资料前请确认符合信息安全规定 |
| 让 Claude / Copilot 读写笔记 | 命令「MCP 服务器…」复制配置 |
| 学习 | 「学习」面板：手册 → 结构图、卡片复习、章节笔记、跨芯片对比、初始化清单 |
