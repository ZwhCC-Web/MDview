# 版本记录

## 1.4.0 · 2026-10-28（Atlas）

**IP 图谱（新功能面板）** —— 详见 `docs/IP-ATLAS.md`
- 左侧新增“IP 图谱”（Ctrl+Shift+I）：按 IP 分组列出芯片页面，可筛选；每页 = 一个 IP × 一颗芯片。
- 整页视图分标签：概览（关键参数）、结构、场景动画、寄存器（可搜索）、时序、代码、要点与坑、芯片对比、交互实验台。
- 新组件 ```scene：在结构图上逐步讲解——单步 / 播放 / 键盘 ← →，高亮模块与连线、数据包沿连线移动、镜头跟随；右侧同步显示讲解、寄存器变化（按页面里的寄存器定义逐位解码，变化字段高亮）、代码行与手册页码。也可以在任何笔记里使用。
- 芯片对比：同一 IP 的所有芯片按 facts 参数并排，寄存器对照，不同之处高亮。
- 页面检查：结构图连线、场景引用的模块 / 连线 / 寄存器 / 代码行、缺少的手册页码。
- 新建页面向导（带模板）；内置示例只读，可“复制到工作区”后编辑；在整页视图里“确认 / 有疑问”会直接写回文件。
- 内置示例：CAN-FD · RH850/U2B（由 RS-CANFD Lab v10.1 整理：13 个模块、3 个场景共 21 步、33 个寄存器、2 个时序图、3 段代码，并附带实验台）。尚未逐项标注页码，状态“待核对”。

**MCP：34 → 41 个工具，6 个提示词模板，16 个技能**
- atlas_list / atlas_read / atlas_create_page / atlas_write_section / atlas_add_scene / atlas_validate / atlas_compare。
- 提示词模板 `build-ip-atlas`；技能 `ip-atlas-author`（从手册建页的步骤与写法）。
- 内置示例只读，AI 写入后页面状态自动变为“待核对”。

## 1.3.0 · 2026-10-28（Mold）

**IP 结构图（新组件 `ipblock`）**
- 用 YAML 描述模块（blocks）、分组 / 子系统（groups，可嵌套）、连线（links：总线 / 数据 / 时钟 / 中断 / DMA / 控制），由 **elkjs（Eclipse Layout Kernel）** 自动布局：分层排布、正交走线、模块放进所属分组框、连线可以跨分组。
- 交互：点模块看类型、所属、地址、寄存器、上下游连线、手册页码；相关连线高亮；“确认 / 有疑问”写回 YAML；横向 / 纵向切换；导出 SVG。
- 从 CMSIS-SVD 生成外设总览：按 `groupName` 分组，带基地址，中断连到中断控制器（工程工具 →“从 SVD 生成外设结构图”）。
- 布局在 Web Worker 里计算并缓存，不卡界面。新增库 `lib/elk/elk-worker.js`（elkjs 0.9.3，EPL-2.0）。

**文档缩放**
- 笔记和所有查看器支持 **Ctrl + 滚轮** 与 **Ctrl+= / Ctrl+-**；每个文件记住自己的缩放；状态栏显示百分比，点击恢复 100%（笔记 Ctrl+Alt+0，查看器 Ctrl+0）。PDF 按渲染倍率放大，保持清晰。界面本身不会被缩放。

**工作区主文件夹**
- 新建工作区时可选一个（空）文件夹：自动建 `笔记 / 收件箱 / 日志 / .chipbench`，并另存一份便携 `<工作区名>.cbws`。
- 新笔记 Ctrl+S 直接存入“笔记”，按标题命名，重名自动加序号；“另存为”默认打开该文件夹（偏好设置可关闭）。
- 本工作区的搜索索引、历史版本、AI 记录存在 `<主文件夹>\.chipbench\`。

**数据目录**
- 偏好设置 → 数据与存储：可改到任意文件夹（自动复制现有数据，重启生效）、恢复默认；便携模式（exe 旁的 `data` 文件夹）。MCP 用同样的规则找数据目录。
- 新增 Rust 命令 `data_dir_get` / `data_dir_set`；`save_dialog` 支持起始文件夹。

**MCP：23 → 34 个工具**
- `get_workspace_info`、`list_dir`、`find_files`、`grep_files`、`search_pdf`（PDF 手册全文搜索，带页码）、`add_task`、`set_task_done`、`append_journal`、`evaluate_clocktree`、`decode_register`、`describe_ipblock`。

**界面修复（含 1.2.1 审查结果）**
- 矮窗口下侧栏撑高窗口、状态栏被挤出；弹出菜单 Esc 关不掉；过小字号与低对比度；版本面板英文原始报错；邮件正文固定高度；数字列表头不对齐；规划页标题在窄窗口下逐字竖排、关闭按钮被挤出。

## 1.2.0 · 2026-10-27（Bond）—— UI 修复版

**界面**
- 修复：点击工具或面板后整个界面被“顶上去”——左侧图标栏、标签栏、工具栏消失，下方出现大片空白。原因是外层容器虽设为 overflow:hidden，仍会被 scrollIntoView / focus 程序性滚动；现改为 overflow:clip，并在外壳上加了复位保护。
- 修复：帮助与手册只占 70% 高度、下方空白；全屏页覆盖了左侧图标栏；左侧目录文字被截断。
- 修复：窄窗口（<1000 px）下侧栏自动隐藏为浮层、点一下就消失的问题；改为始终停靠、自动变窄。
- 修复：窄窗口下“实时 / 源码 / 分屏 / 阅读”按钮逐字竖排；格式工具栏被截断（改为可横向滚动）。
- 修复：文档开头的 front matter（title / status / tags）在实时预览里被渲染成大号蓝色标题。
- 工程工具、学习中心改为紧凑列表：去掉顶部说明块和卡片边框，每项一行（图标 + 名称 + 灰色简述，悬停看完整说明）；去掉造成重复的“最近使用”。
- 表格公式直接显示计算结果（悬停看公式）。

**AI**
- 网络权限范围改为 `https://*/*` 等完整路径匹配（1.1 的 `https://*` 可能拒绝 /v1/chat/completions 之类带路径的请求）。
- 新增“测试连接”（设置对话框与 AI 面板）；失败时按原因给出可操作的说明。
- AI 面板顶部显示当前服务 / 模型 / 工具调用状态；未配置时显示配置引导。
- 修复：启动后立即发送时，凭据管理器里的 Key 还没读完导致误报“未配置”。

**发布**
- 支持代码签名：设置环境变量 `CHIPBENCH_CERT_THUMBPRINT` 后运行 `build-windows.bat`，exe 与安装包自动签名并加时间戳。说明见 `docs/SIGNING.md`。

## 1.1.0 · 2026-10-27（Die）

**界面与布局**
- 窗口宽度三档自适应：≥1400 并排；1000–1399 右侧面板浮动；<1000（半屏）侧栏改为浮层、分屏上下排列、工具栏横向滚动、PDF 重新适应宽度。
- 打字机模式。
- 排版统一：字号收敛为 6 档（11 / 12 / 13 / 15 / 20 / 28 px，`--fs-*`），间距统一为 `--sp-*` 刻度（原 138 处写死的像素值改为变量）；正文 16 px / 行高 1.75。
- 待办日期符号（⏳ 📅 ✅ ⏰）在编辑器、预览、规划中改为 SVG 线条图标，不再依赖系统表情字体。

**资料与知识**
- 右侧“上下文”面板：看 PDF 时显示引用本页的笔记和出自本页的组件节点；看笔记时显示引用的手册页、各组件的确认进度和反向链接。
- PDF 选区“摘录到笔记”，自动附带页码引用。
- 时钟树 / 结构图节点编辑：编辑、新增下游节点、删除、把“假设分析”的倍频分频写回源码。
- 从 SVD 批量导入寄存器块。

**AI**
- 内置助手支持工具调用（15 个工具，与 MCP 能力对齐），支持 OpenAI 兼容、Azure OpenAI、Ollama；不支持时自动退回普通对话。
- AI 写入前差异确认；AI 记录面板，可撤销每次修改。
- AI 不能把节点标成“已确认”（内置助手与 MCP 同一规则）。
- API Key 改存 Windows 凭据管理器（新增 Rust 命令 `secret_get` / `secret_set`，依赖 `keyring` crate）。
- MCP：新增 `read_pdf_pages`（读取桌面端的 PDF 文字缓存），共 23 个工具。

**性能**
- 实时预览：后台语法分析的中间进度不再触发装饰重算（合并为一次）。
- 分屏预览：刷新延迟按文档长度自适应（短文档 30 ms，长文档 70–110 ms）。
- 格式工具栏状态在输入时延后 90 ms 更新，不再每个按键都遍历按钮。
- 搜索索引持久化：重启后直接恢复索引，只重读有变化的文件。
- 中文字体切片：常用字（GB2312 一级 + 标点 + 假名）约 1 MB 先加载，生僻字才加载完整字体。

**工程**
- 扩展命名空间对外名称改为 `SL.ext`（`SL.s31` 保留为别名）。
- 新增 `tests/t_v11.py`（39 项）；MCP 测试增加 PDF 缓存读取与“不可自确认”规则。
