# ChipBench 使用手册

> 版本 1.4.0 · 制作：Wenhao Zhao · 本手册随程序附带，可在应用内按左侧栏最下方的 **“帮助与手册”** 打开。

## 1. ChipBench 是什么

ChipBench 是**芯片应用工程师（AE）的工作台**（前身为 Silica）。你按芯片或项目自己建工作区，把分散的手册、代码、PPT、抓包和日志放进来统一打开、查找、编辑，并沉淀成带出处的工程知识；外部 AI 通过 MCP 和技能接入同一个工作区。

| 你要做的事 | 在 ChipBench 里 |
| --- | --- |
| 写笔记、方案、FAQ、培训讲稿 | Markdown 编辑器（实时预览 / 源码 / 分屏 / 阅读） |
| 查数据手册、勘误、客户资料 | PDF、Excel、Word、PPT、邮件、网页查看器 |
| 看固件、构建与日志 | HEX / S-record / ELF、.map、.su、GB 级日志查看器 |
| 管任务与一天的安排 | 待办规划（今日 / 本周 / 计时 / 周报） |
| 把手册读成自己的知识 | 学习中心（结构图、复习卡片、资料卡片） |
| 临时算个数 | 工程工具（换算、波特率、CAN 位时序、寄存器、CBS） |
| 查车载以太网问题 | 抓包查看器（gPTP / DoIP / SOME/IP）、TAS 门控列表、时序图 |
| 让 AI 帮忙 | AI 助手、内置 AI 工具调用、MCP 服务（41 个工具）、技能库（15 个内置技能） |

**一条原则：文档留在原处。** ChipBench 只记录“路径与上下文”，不搬走、不改写你的文件，除非你自己保存。

## 2. 界面速览

- **最左侧竖条**：5 个主入口——工作区、搜索、学习中心、工程工具、规划；其下是两个次级入口（大纲 Ctrl+Shift+U、版本历史）；底部是 AI、偏好设置、帮助。
- **标签栏**：每个文档一个标签；有未保存修改时标签上出现圆点；中键关闭。
- **面包屑栏**（标签下方）：当前文件位置；右侧是模式切换（实时 / 源码 / 分屏 / 阅读）。
- **格式工具栏**（面包屑栏下方，仅笔记显示）：标题菜单、粗体 / 斜体 / 删除线 / 高亮 / 行内代码 / 链接 / 图片、列表 / 待办 / 引用、代码块 / 公式 / 表格 / 分隔线 / 提示框、插入菜单、撤销重做、查找；右侧是大纲、演示、保存。阅读模式下编辑按钮自动变灰。
- **状态栏**：模式、编码、字数、行列、阅读时间。
- **右侧面板**（Ctrl+Shift+R）：链接、**上下文**（Ctrl+Alt+R）、AI、**AI 记录**。

### 2.1 窗口大小（1.1）

| 窗口宽度 | 布局 |
| --- | --- |
| ≥ 1400 px | 侧栏、正文、右侧面板并排 |
| 1000–1399 px | 右侧面板改为浮在正文上，正文不被挤窄 |
| < 1000 px（半屏） | 侧栏保持停靠、自动变窄（Ctrl+B 可手动收起）；右侧面板浮在正文上；分屏改为上下排列；格式工具栏可横向滚动；PDF 自动重新适应宽度 |

全屏 F11，专注模式 F8；命令面板里的“打字机模式”让光标所在行保持在屏幕中间。

### 2.2 缩放

| 操作 | 作用 |
| --- | --- |
| Ctrl + 滚轮 / Ctrl+= / Ctrl+- | 放大或缩小当前文档 |
| 点状态栏的百分比 · Ctrl+Alt+0（笔记）· Ctrl+0（查看器） | 恢复 100% |

每个文件记住自己的缩放。界面本身不缩放；需要整体放大请用 Windows 显示缩放。偏好设置里的“文档字号”是所有笔记的基准字号。

## 3. 写笔记

### 3.1 四种模式

| 模式 | 用途 | 快捷键 |
| --- | --- | --- |
| 实时预览 | 边写边看渲染效果；光标进入某段时显示它的 Markdown 源码 | 默认 |
| 源码 | 纯文本编辑，语法着色，适合大文件 | Ctrl+/ |
| 分屏 | 左源码右预览，按行同步滚动 | Ctrl+Alt+/ |
| 阅读 | 只读排版，适合评审与打印 | Ctrl+Alt+E |

### 3.2 常用格式

- **标题**：工具栏“正文 ▾”菜单，或 Ctrl+0（正文）～ Ctrl+6（六级标题）。
- **粗体 / 斜体 / 行内代码 / 链接**：Ctrl+B / Ctrl+I / Ctrl+E / Ctrl+K；删除线 Ctrl+Shift+5；高亮 Ctrl+Shift+H。
- **列表 / 待办 / 引用**：工具栏按钮；对多行选区同时生效，再点一次取消；列表之间可直接互相转换。
- **代码块**：Ctrl+Shift+K；工具栏代码块按钮右半边可直接选语言（C、Python、Verilog、汇编…）。
- **公式**：行内 `$a^2+b^2=c^2$`，块级 `$$ … $$`（Ctrl+Shift+M）。
- **表格**：工具栏表格按钮选择行列；Tab / Shift+Tab 在单元格间移动。
- **提示框**：`> [!NOTE]`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION`。

### 3.3 斜杠菜单与自动补全

- 行首输入 `/` 弹出插入菜单（支持拼音首字母，如 `/bg` = 表格，`/lct` = 流程图）。
- 输入 `[[` 补全笔记名（双链），输入 `:rocket` 之类补全 Emoji。
- 粘贴来自 Word / Excel / 网页的内容会自动转成 Markdown（Excel 变成表格）。

### 3.4 图表与专用代码块

| 语言 | 作用 |
| --- | --- |
| `mermaid` | 流程图、时序图、状态图（配色与字体跟随主题） |
| `clocktree` | 时钟树：改分频自动重算，超限标红，附波特率 / CAN / 定时器推算；点节点可**编辑、新增下游节点、删除**，改动写回 YAML |
| `structure` | 结构图 / 数据流：节点带页码，可逐步演示 |
| `register` | 寄存器位域：值 ⇄ 位域；命令面板“从 SVD 导入寄存器…”可批量生成 |
| `pinout` | 引脚图（QFP / BGA），按功能高亮 |
| `memmap` | Flash / RAM 占用图 |
| `query` | 按属性汇总笔记，表格或看板（看板拖动会改回笔记属性） |
| `partdecode` | 料号解码 |
| `chart` | 折线 / 柱状图 |

### 3.4a 表格公式（1.2）

表格单元格写 `=B2*C2`、`=SUM(D2:D9)` 等公式，实时预览和阅读模式直接显示计算结果（鼠标悬停看公式）；源码里保留公式。需要把结果固化成数字时，用命令“计算表格公式”。

### 3.4b 文档属性（Front matter）

文档开头 `---` 包住的 `title:` / `status:` 等是文档属性，编辑器里以等宽小字显示，不会被当成标题。

### 3.4c IP 结构图（`ipblock`）

用 YAML 描述 MCU / IP 的模块与连线，ChipBench 用 ELK 自动排版：

````
```ipblock
title: CAN 控制器结构
source: 手册.pdf
direction: right            # right 横向 / down 纵向
groups:
  - {id: core, label: 协议控制器}
blocks:
  - {id: bus,  label: APB 接口, kind: bus, page: 1200}
  - {id: pe,   label: 协议引擎, kind: logic, group: core, regs: [CFDC0NCFG]}
  - {id: ram,  label: 消息 RAM, kind: mem, group: core}
  - {id: intc, label: 中断控制器, kind: irq}
links:
  - {from: bus, to: core, kind: bus, label: 寄存器访问}
  - {from: pe,  to: ram,  kind: data}
  - {from: pe,  to: intc, kind: irq}
```
````

- `kind`（模块）：cpu / bus / mem / dma / periph / logic / io / clock / irq / ext / analog，决定左侧色条。
- `kind`（连线）：bus / data / clock / irq / dma / ctrl，决定颜色和线型；`both: true` 画双向箭头。
- 模块可写 `page`（手册页码，可点击跳转）、`regs`、`addr`、`note`、`status`。
- 点模块看详情并“确认 / 有疑问”；工具栏可切换方向、导出 SVG。
- 工程工具 →“从 SVD 生成外设结构图”：读 CMSIS-SVD，自动生成外设总览（RA、RZ 等 Arm 内核芯片可用）。

### 3.5 待办与日期标记

`- [ ] 回复样品付款方式 ⏳ 2026-10-21 📅 2026-10-22 ~30m !!`

`⏳` 计划日期 · `📅` 截止日期 · `✅` 完成日期 · `⏰` 时间 · `~30m / ~2h` 预计用时。规划面板会读取这些标记。实时预览和阅读模式里，这些符号显示为统一的线条图标（光标移上去时显示原文）。

## 4. 工作区

工作区是**项目的资料入口**，不是文件副本：**根文件夹**（实时显示磁盘目录）、**集合**（手工整理的引用，同一文档可出现在多个集合；也可放网页链接和保存的搜索）、**会话**（记住打开了哪些文档）、**设置**（收件箱等）。找不到的文件会标记为“找不到”，可以重新定位。

### 4.1 工作区主文件夹

新建工作区时选一个空文件夹作为主文件夹：

```
<主文件夹>\
├─ 笔记\          新建笔记 Ctrl+S 直接存到这里（按标题命名）
├─ 收件箱\        随手记、网页剪藏
├─ 日志\          今日日志
├─ .chipbench\    本工作区的索引、历史版本、AI 记录、MCP 写入备份
└─ <工作区名>.cbws 便携工作区文件，拷到别的电脑双击即可打开
```

已有工作区：工作区设置 → 主文件夹 → 设置…。手册、代码等外部文件夹照常添加，只记录路径。

### 4.2 数据目录

偏好设置 → 数据与存储：默认在 `%USERPROFILE%\.chipbench`。“更改…”会把现有数据复制到新位置（原目录保留），重启生效；“恢复默认”改回。在 chipbench.exe 旁新建 `data` 文件夹即进入便携模式。API Key 始终在 Windows 凭据管理器。

### 4.3 IP 图谱（1.4）

左侧“IP 图谱”（Ctrl+Shift+I）按 IP 分组列出芯片页面，每页包含结构图、场景动画、寄存器、时序、代码与芯片对比。格式与用法见 `docs/IP-ATLAS.md`（帮助中心 → IP 图谱）。

## 5. 查看资料

| 类型 | 能做什么 |
| --- | --- |
| **PDF** | 选中文字 →“**摘录到笔记**”：以引用块插入最近编辑的笔记，并附 `[[手册.pdf#p=页码]]`；只渲染可见页；书签、搜索、高亮与批注（另存为 Markdown，不改原 PDF）；`[[手册.pdf#p=123]]` 跳页；阅读进度自动记录 |
| **PowerPoint** | **3.1 新**：软件内按原版式显示（主题色与字体、占位符、形状、图片、表格、简单图表、备注），逐页懒加载，左侧缩略图，可搜索文字；“高保真”调用本机 Office / LibreOffice 转 PDF（结果按修改时间缓存） |
| **Word** | 快速预览，可转为 Markdown；“高保真”同上 |
| **Excel / CSV** | 选区转 Markdown 表格、数值列画曲线 |
| **邮件 .eml / .msg** | 正文与附件，可存成笔记 |
| **网页 / .html** | **3.1 新**：脚本可运行，相对路径的 CSS / JS / 图片 / 字体自动内联；localStorage 被保存；需要完整能力时点“在独立窗口打开” |
| **固件 / .map / 日志** | 十六进制查看、两版固件对比；链接图占用与差异；GB 级日志流式查看与过滤 |

## 6. 待办规划

侧栏“规划”：**今日**（待选池 + 时间轴，拖动安排，超过 8 小时提醒）、**本周**（七列拖动）、一键顺延、今日回顾、周报草稿、任务计时与时间复盘。所有勾选与日期调整都写回原笔记。

## 7. 学习中心

**定义**：把手册读成**你核对过的知识**。AI 只起草，每个节点必须带页码，须由你从“待核对”改为“已确认”。

| 功能 | 说明 |
| --- | --- |
| 手册 → 结构图 | 选 PDF 章节与结构类型（时钟树、CAN、以太网、芯片框图、软件架构、自定义），生成 YAML 并画图；数值会与原文页比对，找不到的标黄 |
| 复习卡片 | 在笔记里写 `Q: 问题 p.12` / `A: 答案`；按 SM-2 间隔复习 |
| 资料卡片库 | 每份 PDF / 网页 / 表格一张卡片，汇总批注，可用 `[[双链]]` 引用 |
| 章节笔记 | 按 PDF 书签批量创建，并记录学习进度 |
| 原图热区 / 跨芯片对比 | 在手册框图上圈区域链接页码；两颗芯片同类结构并排 |
| 初始化顺序清单 / 模块寄存器树 | 由结构图生成初始化步骤；用 SVD 把节点与寄存器关联 |

> 手册多为保密资料：使用“手册 → 结构图”“AI 卡片”前，请确认只连接公司批准的 AI 服务；不需要 AI 的功能完全本地运行。

## 8a. 车载以太网

- **抓包查看器**：直接打开 `.pcap` / `.pcapng`。顶部是“发现的问题”（点击跳到对应帧）和 gPTP、DoIP、SOME/IP-SD、VLAN 统计卡片；下面是可过滤的报文列表。“生成分析笔记”把结果写成 Markdown。
- **```gcl 块**：TAS（802.1Qbv）门控列表。显示 8 个队列的时间轴和每个队列的开门占比、最长等待，并检查周期、Express / Preemptable 映射和保护带。
- **```wavedrom 块**：信号时序图（WaveDrom 语法的常用子集）。
- **CBS 计算器**：802.1Qav 的 idleSlope / sendSlope / hiCredit / loCredit。

详见“ETHERNET”文档。

## 8b. 技能库

技能是带 `SKILL.md` 的文件夹，AI 工具（Copilot、Claude、Cursor）可以直接使用。按 **Ctrl+Alt+S** 打开技能库：搜索、打开说明、**安装到工作区**（复制到 `<根目录>\.agents\skills\`）、新建技能。内置 15 个技能，覆盖手册提取、CAN、.map、周报、客户回复和车载以太网。详见“SKILLS”文档。

## 9. AI 与 MCP

- **AI 助手**（Ctrl+J）：OpenAI 兼容、Azure OpenAI、本地 Ollama。处理公司资料前请确认合规；需要数据不出本机时选 Ollama。
- **工具调用（1.1）**：在 AI 设置里打开“允许调用工具”后，内置助手可以自己搜索工作区、读文件和 PDF 页、读写工程组件、分析抓包、算 CBS / CAN 位时序、读取技能。对话里会逐条显示调用了什么。模型或服务不支持工具调用时自动改用普通对话。
- **写入受控**：AI 修改文件前弹出差异对比，由你允许或拒绝；AI 改过的组件节点一律标为“待核对”，AI 不能自己把节点标成“已确认”。
- **AI 记录**（右侧面板）：列出 AI 读过、改过的文件；每次修改都可以一键撤销。
- **API Key** 保存在 Windows 凭据管理器，不写入设置文件。
- **测试连接（1.2）**：AI 设置里和 AI 面板里都有“测试连接”。失败时会直接说明原因（Key 无效、地址或模型名不对、连不上 / 需要代理、模型不支持工具调用等）和怎么改。
- **公司网络**：如果必须走代理，在 Windows 系统代理里配置，或设置环境变量 `HTTPS_PROXY` 后重启 ChipBench。
- **MCP 服务**：`mcp/chipbench_mcp.py`，让 Copilot、Claude、Cursor 等读写你的工作区；写入前自动备份。需要 Python 3.8+。
  - 23 个工具（1.1 新增 `read_pdf_pages`，读取 ChipBench 已缓存的 PDF 文字）：笔记读写、任务、读取任意文本文件（代码 / .map / 日志）、**工程组件读写**（AI 改动自动标记“待确认”）、**技能**、**抓包分析 / TAS 检查 / CBS / CAN 位时序**。
  - 5 个提示词模板：读手册章节、周报、抓包分析、设计 TAS、复核组件。

## 11. 常见问题

- **打开 exe 时 Windows 提示有风险**：程序没有数字签名导致，见 `docs/SIGNING.md`。
- **AI 没反应**：先在 AI 面板点“测试连接”，按提示处理。

- **打开 exe 时 Windows 提示有风险**：程序没有数字签名导致，见 `docs/SIGNING.md`。
- **AI 没反应**：先在 AI 面板点“测试连接”，按提示处理。

**网页只显示文字、脚本没加载？** 已修复；若页面使用 IndexedDB、Service Worker 或本地文件选择器，请点“在独立窗口打开”。

**PPT 里的图表 / SmartArt 显示成灰色方框？** 简单图表（柱 / 折线 / 饼）会直接绘制；复杂图表与 SmartArt 请点“高保真”。

**数据在哪里？** 工作区、缓存与设置在 `%USERPROFILE%\.chipbench\`；文档与图片留在原处。

**反馈问题时请附上**：版本号（关于页）、操作步骤、截图，以及控制台里以 `[s31]` / `[pptx]` / `[net]` 开头的警告。

**从 Silica 升级后数据还在吗？** 在。首次启动时 `%USERPROFILE%\.silica\` 会改名为 `.chipbench\`，`.silicaws` 工作区改为 `.cbws`，旧白板仍可打开。MCP 配置里的脚本名需要改为 `chipbench_mcp.py`。
