# 路线图

## 1.0 已完成
- 产品更名为 ChipBench，统一版本号、数据目录与文件格式，提供从 Silica 自动迁移。
- 补丁式的 3.1 模块改为正式模块名；三个样式表合并为一个；清理备份文件。
- 左栏收敛为 5 个主入口（工作区、搜索、学习中心、工程工具、规划）；大纲和版本历史降为次级入口。
- 车载以太网：抓包查看器、gcl 组件、CBS 计算器、wavedrom 时序图。
- MCP：从 12 个工具扩展到 22 个，新增提示词模板、技能资源、组件读写。
- 技能库：15 个内置技能 + 应用内管理。

## 1.1 已完成
- 窗口自适应（宽 / 中 / 半屏）、打字机模式、字号与间距变量统一、SVG 任务图标。
- 右侧上下文面板；PDF 摘录到笔记带页码。
- 时钟树 / 结构图节点编辑（表单式）；SVD 导入寄存器。
- 内置 AI 工具调用、写入确认、AI 记录与撤销；API Key 进凭据管理器；MCP `read_pdf_pages`。
- 性能：装饰重算合并、预览自适应延迟、索引持久化、字体切片。

## 1.2 已完成（UI 修复版）
- 外壳不再被程序性滚动（图标栏 / 标签栏消失、下方空白）；窄窗口侧栏常驻；帮助页铺满；工具与学习中心改为紧凑列表；front matter 不再显示成标题；表格公式显示结果。
- AI：网络权限范围修正、测试连接、错误诊断、状态行。
- 代码签名支持。
- 性能：Mermaid 图滚到可见区域、空闲时才渲染。

## 1.3 已完成
- `ipblock` IP 结构图：elkjs 自动布局（分组嵌套、正交走线）、交互核对、SVG 导出、SVD 外设总览导入。
- 文档缩放；工作区主文件夹；可选数据目录与便携模式。
- MCP 23 → 34 个工具；1.2.1 界面审查修复。

## 1.4 已完成
- IP 图谱面板、scene 场景组件、芯片对比、页面检查、7 个 atlas MCP 工具、ip-atlas-author 技能、CAN-FD · RH850/U2B 内置示例。

## 1.5 计划
- 内置示例补齐手册页码；增加 Ethernet（U2B TSN / RSWITCH）、DMA、时钟、中断等页面。
- 结构图 / 时钟树拖拽编辑；IP-XACT 导入。

## 1.4 原计划
- 现有 `structure` / `clocktree` 也改用 ELK 布局（端口位置、正交走线）。
- 导入器：IP-XACT（IEEE 1685）→ ipblock + register；Linux `clk_summary` → clocktree。
- ipblock 拖拽编辑（拖动改分组、拖线建连接，写回 YAML）；端口（ports）级连线。
- 内置常用 IP 模板（CAN-FD、Ethernet MAC、DMA、中断控制器）——需按具体芯片手册核对后再发布。
