# 产品定义（ChipBench 1.0）

## 一句话
**ChipBench 是芯片 AE 的工作台：按芯片或项目建工作区，把分散的手册、代码、PPT、抓包和日志统一打开、查找、编辑，沉淀成带出处的工程知识；外部 AI 通过 MCP 和技能接入同一个工作区。**

English: *ChipBench — the workbench for chip application engineers. One workspace per chip or project; every file in one place; knowledge with sources; AI connected through MCP and Agent Skills.*

## 要解决的痛点
AE 每天要看代码、芯片手册、PPT、Excel、邮件、日志和抓包。这些文件格式不同、路径分散，芯片型号一多就更乱：
- 找资料要在几个文件夹、几个软件之间来回切；
- 从手册读出的结论没有出处，过一段时间就无法复核；
- 时钟树、寄存器、引脚、门控列表这类内容，用普通文档很难写清楚，也没法让 AI 准确修改。

## 四条原则
1. **工作区由你定义**：按芯片、客户或项目自己建，一个工作区可以挂多个文件夹。ChipBench 不强加“芯片”这一层结构。
2. **文件留在原处**：只记录路径和索引。
3. **结论带出处**：组件节点和笔记结论都能链回手册页码、代码行或抓包帧号。
4. **AI 可接入但受控**：AI 写入前备份，组件改动标记“待确认”，由人核对。

## 平台结构

| 层 | 作用 | 主要入口 |
|---|---|---|
| ① 工作区 | 根目录、集合、最近、全文搜索 | 左栏“工作区”“搜索” |
| ② 阅读与编辑 | 多格式查看、Markdown 笔记、摘录、对比 | 标签页 |
| ③ 工程组件 | clocktree / structure / register / pinout / memmap / gcl / wavedrom | 笔记里的代码块；左栏“工程工具” |
| ④ 计划 | 待办、日 / 周规划、周报 | 左栏“规划” |
| ⑤ AI 接口 | MCP 服务、技能库（1.6 起不内置 AI） | 命令“MCP 服务器…”、技能库（Ctrl+Alt+L） |

## 判断新功能的标准
**它能不能让 AE 在一个工作区里，更快地找到、看懂或沉淀资料？** 不能的就不进主界面，最多放进命令面板。

## 主次
- **核心**：工作区、多格式查看、工程组件、车载以太网工具、MCP 与技能。
- **支撑**：笔记、双链、搜索、PDF 批注、版本历史。
- **外围（只在命令面板里）**：白板、演示、复习卡片、导出 PPTX / 邮件草稿、网页剪藏。
