# 设计说明（ChipBench 1.0）

参考：Fluent 2（分层中性色、4px 间距体系、圆角与阴影阶梯）、Linear（单一强调色、细边框、克制的字重）、Obsidian / 阅读类编辑器（16px 正文、约 1.7 行高、约 72 字版心）。
- 左侧窄栏 + 面板的信息架构（工作区 / 搜索 / 大纲 / 规划 / 学习 / 版本 / 工具 / AI / 设置）；
- 浅色、深色、Graphite 三套主题，强调色与界面密度可调；
- 状态一律用小标签（chip），文件类型用彩色文字徽标（MD / PDF / XLS / DOC / PPT…）；
- 动效只用于反馈（120–200 ms）。
截图见 `docs/screenshots/`。注意：截图在 Linux 无头浏览器中生成，`⏳ ⏰ 📅` 等表情符号因缺少字体显示为方框，Windows 上由 Segoe UI Emoji 正常显示。

## 1.0 调整
- 样式合并为单一的 `app/css/chipbench.css`（按原有层叠顺序：基础 token → 面板 → 排版与抛光 → 1.0 新组件）。
- 左栏：5 个主入口；次级入口（大纲、版本历史）缩小并降低不透明度，悬停或激活时恢复。
- 以太网组件的语义色：Express 队列用青绿（#0F9D8A），Preemptable 用琥珀（#B26B00），其他队列用强调色；问题一律用 chip（bad / warn / ok）。
- 时序图数据块沿用 WaveDrom 的配色习惯（2–9 号色），深色主题下降低填充不透明度。
