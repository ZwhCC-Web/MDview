# 版本记录

## 1.2.0 · 2026-10-27（Bond）—— UI 修复版

**界面**
- 修复：点击工具或面板后整个界面被“顶上去”——左侧图标栏、标签栏、工具栏消失，下方出现大片空白。原因是外层容器虽设为 overflow:hidden，仍会被 scrollIntoView / focus 程序性滚动；现改为 overflow:clip，并在外壳上加了复位保护。
- 修复：帮助与手册只占 70% 高度、下方空白；全屏页覆盖了左侧图标栏；左侧目录文字被截断。
- 修复：窄窗口（<1000 px）下侧栏自动隐藏为浮层、点一下就消失的问题；改为始终停靠、自动变窄。
- 修复：窄窗口下“实时 / 源码 / 分屏 / 阅读”按钮逐字竖排；格式工具栏被截断（改为可横向滚动）。
- 修复：文档开头的 front matter（title / status / tags）在实时预览里被渲染成大号蓝色标题。
- 工程工具、学习中心改为紧凑列表：去掉顶部说明块和卡片边框，每项一行（图标 + 名称 + 灰色简述，悬停看完整说明）；去掉造成重复的“最近使用”。
- 表格公式直接显示计算结果（悬停看公式）。

**AI**
- 网络权限范围改为 `https://*/*` 等完整路径匹配（1.1 的 `https://*` 可能拒绝 /v1/chat/completions 之类带路径的请求）。
- 新增“测试连接”（设置对话框与 AI 面板）；失败时按原因给出可操作的说明。
- AI 面板顶部显示当前服务 / 模型 / 工具调用状态；未配置时显示配置引导。
- 修复：启动后立即发送时，凭据管理器里的 Key 还没读完导致误报“未配置”。

**发布**
- 支持代码签名：设置环境变量 `CHIPBENCH_CERT_THUMBPRINT` 后运行 `build-windows.bat`，exe 与安装包自动签名并加时间戳。说明见 `docs/SIGNING.md`。

## 1.1.0 · 2026-10-27（Die）

**界面与布局**
- 窗口宽度三档自适应：≥1400 并排；1000–1399 右侧面板浮动；<1000（半屏）侧栏改为浮层、分屏上下排列、工具栏横向滚动、PDF 重新适应宽度。
- 打字机模式。
- 排版统一：字号收敛为 6 档（11 / 12 / 13 / 15 / 20 / 28 px，`--fs-*`），间距统一为 `--sp-*` 刻度（原 138 处写死的像素值改为变量）；正文 16 px / 行高 1.75。
- 待办日期符号（⏳ 📅 ✅ ⏰）在编辑器、预览、规划中改为 SVG 线条图标，不再依赖系统表情字体。

**资料与知识**
- 右侧“上下文”面板：看 PDF 时显示引用本页的笔记和出自本页的组件节点；看笔记时显示引用的手册页、各组件的确认进度和反向链接。
- PDF 选区“摘录到笔记”，自动附带页码引用。
- 时钟树 / 结构图节点编辑：编辑、新增下游节点、删除、把“假设分析”的倍频分频写回源码。
- 从 SVD 批量导入寄存器块。

**AI**
- 内置助手支持工具调用（15 个工具，与 MCP 能力对齐），支持 OpenAI 兼容、Azure OpenAI、Ollama；不支持时自动退回普通对话。
- AI 写入前差异确认；AI 记录面板，可撤销每次修改。
- AI 不能把节点标成“已确认”（内置助手与 MCP 同一规则）。
- API Key 改存 Windows 凭据管理器（新增 Rust 命令 `secret_get` / `secret_set`，依赖 `keyring` crate）。
- MCP：新增 `read_pdf_pages`（读取桌面端的 PDF 文字缓存），共 23 个工具。

**性能**
- 实时预览：后台语法分析的中间进度不再触发装饰重算（合并为一次）。
- 分屏预览：刷新延迟按文档长度自适应（短文档 30 ms，长文档 70–110 ms）。
- 格式工具栏状态在输入时延后 90 ms 更新，不再每个按键都遍历按钮。
- 搜索索引持久化：重启后直接恢复索引，只重读有变化的文件。
- 中文字体切片：常用字（GB2312 一级 + 标点 + 假名）约 1 MB 先加载，生僻字才加载完整字体。

**工程**
- 扩展命名空间对外名称改为 `SL.ext`（`SL.s31` 保留为别名）。
- 新增 `tests/t_v11.py`（39 项）；MCP 测试增加 PDF 缓存读取与“不可自确认”规则。

## 1.0.0 · 2026-10-27（Wafer）

产品更名为 **ChipBench**，定位为“芯片 AE 的工作台”。版本号从 1.0 重新开始；Silica 3.x 的记录保留在下方。

**产品与结构**
- 更名：应用、安装包、数据目录（`.chipbench`）、工作区文件（`.cbws`）、白板（`.cbboard`）、MCP 脚本（`chipbench_mcp.py`）全部更名。首次启动自动从 Silica 迁移（Rust 侧迁移代码尚未在 Windows 编译验证）。
- 左栏收敛为 5 个主入口：工作区、搜索、学习中心、工程工具、规划；大纲和版本历史降为次级入口。
- 3.1 的补丁模块改为正式模块名（integration、format-toolbar、viewer-pptx、viewer-html、panels-pro、help、docs-data）；三个样式表合并为 `chipbench.css`；删除 `.bak` 文件和旧补丁安装测试。

**车载以太网（新）**
- `.pcap` / `.pcapng` 查看器：gPTP、DoIP（含 UDS 服务与 NRC）、SOME/IP 与 SOME/IP-SD、VLAN/PCP、AVTP、LLDP；问题清单（路由激活失败、NRC、Sync 间隔异常、Pdelay 无响应、TCP RST / 重传、订阅无 Ack）；过滤；生成分析笔记。
- ```gcl 组件：TAS 门控列表时间轴与检查。```wavedrom 组件：信号时序图。CBS 计算器。

**AI**
- MCP 工具从 12 个增加到 22 个：read_file、list_components、get_component、update_component、list_skills、read_skill、analyze_capture、check_gcl、calc_cbs、calc_can_timing。
- 新增 5 个提示词模板；技能作为 MCP 资源提供。
- 技能库：15 个内置 Agent Skills，可在应用内搜索、安装到工作区、新建。

**测试**
- 修复性能测试把结果写到仓库根目录、导致预算检查找不到文件的问题。
- 新增 `tests/net.test.js`（19 项）、`mcp/test_aenet.py`（12 项）、`tests/t_net.py`（14 项端到端）、`tools/sync-skills.py --check`；MCP 端到端测试扩充到 37 项。

# Silica 历史版本

## 3.1.0 · 2026-10-22（Parchment）

针对 3.0 反馈的修复与打磨。

**修复**
- **编辑功能**：恢复固定格式工具栏（标题菜单、行内格式、列表 / 待办 / 引用、代码块与语言、公式、表格选择器、提示框、插入菜单、撤销重做、查找、大纲、演示、保存）。
- **网页**：本地 `.html` 的脚本现在会运行；相对路径的 CSS / JS / 图片 / 字体自动内联；`localStorage` 被保存；外链在系统浏览器打开；新增“在独立窗口打开”。
- **PPT**：新增软件内渲染器（版式 / 主题 / 占位符 / 形状 / 图片 / 表格 / 简单图表 / 备注），逐页懒加载；“高保真”转换结果按修改时间缓存。

**界面与排版**
- 正文字体改为 Source Sans + Noto Sans SC（随包附带）；标题、行距、字距与中英文间距重新调校。
- 代码块 / 行内代码（关闭连字）、表格（横线分隔、粘性表头、等宽数字）、公式（基线对齐）、流程图（主题联动）统一风格。
- 标签、侧栏、按钮、输入框、卡片、菜单与浅 / 深 / Graphite 三套主题抛光。

**学习中心 / 工程工具**
- 重新设计：定义说明、统计、分组与说明文字、搜索、最近使用；沿用 3.0 的全部功能。
- 工程工具新增三个插入入口：内存占用图、寄存器位域块、曲线图。

**文档与版本**
- 内置帮助中心：使用手册、快捷键速查、开发说明、版本记录、制作说明与许可；关于页显示版本号。

**已知限制**
- Rust 外壳需要在 Windows 上编译并验证；PPT 渲染器对 SmartArt、复杂图表、EMF / WMF 图片、动画仍为简化显示。
- 本版界面与排版在 Linux 无头浏览器的“替身界面”中验证，真机字体回退需在 Windows 上确认。
